ESP32 API Specification

Your ESP32 firmware should send an HTTP POST request to this endpoint every 2–5 seconds:

POST http://<YOUR_PC_IP>:5000/api/sensor-data 
{
  "device_id": "ESP32-001",
  "patient_id": "P001",
  "heart_rate": 76.5,
  "spo2": 98.2,
  "temperature": 36.7,
  "data_source": "ESP32"
}
Backend Pipeline Executed:
  1. Validates JSON types and required parameters.
  2. Updates device record status to CONNECTED and updates last_seen timestamp.
  3. Stores reading in MySQL with data_source = 'ESP32'.
  4. Checks project monitoring thresholds and automatically dispatches alerts if thresholds are breached.
